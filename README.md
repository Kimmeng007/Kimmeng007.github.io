# Kimmeng007.github.io

Personal portfolio site, built as plain HTML/CSS/JS (no build step) for GitHub Pages.

## Structure

- `index.html` — page content
- `css/style.css` — design tokens (light/dark themes) and layout
- `js/script.js` — theme toggle, mobile nav, scroll-spy, reveal-on-scroll
- `assets/` — static files (CV PDF)

## Local preview

Open `index.html` directly in a browser, or serve the folder locally, e.g.:

```
npx serve .
```

## Deploy

Push to a repository named `Kimmeng007.github.io` on GitHub — Pages serves the root
of the `main` branch automatically. Live at `https://kimmeng007.github.io`.
